# Telegram-бот Qwen (DashScope)

Асинхронный Telegram-бот на **aiogram 3.x**, который общается с моделью **Qwen** через официальный OpenAI-совместимый эндпоинт DashScope.

## Возможности

- Диалог с Qwen с сохранением контекста (в памяти, отдельно для каждого пользователя).
- Команды `/start`, `/new` (сброс истории), `/model <name>` (смена модели).
- Индикатор «печатает…» во время ожидания ответа.
- Обработка ошибок API (неверный токен, таймаут, лимиты).
- Автоматическая разбивка длинных ответов (>4096 символов).

## Требования

- Python 3.10+
- Токен Telegram-бота (`@BotFather`)
- API-ключ Qwen / DashScope

## Установка и запуск

```bash
# 1. Клонируйте репозиторий и перейдите в папку
git clone <repo-url>
cd PDF

# 2. Создайте виртуальное окружение (рекомендуется)
python3 -m venv .venv
source .venv/bin/activate

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Задайте переменные окружения
export TELEGRAM_BOT_TOKEN="123456:ABC-DEF..."
export QWEN_TOKEN="sk-..."
export QWEN_MODEL="qwen-plus"  # необязательно, по умолчанию qwen-plus

# 5. Запустите бота
python bot.py
```

## Переменные окружения

| Переменная           | Обязательная | Описание                                       |
|----------------------|--------------|-------------------------------------------------|
| `TELEGRAM_BOT_TOKEN` | Да           | Токен Telegram-бота от `@BotFather`             |
| `QWEN_TOKEN`         | Да           | API-ключ Qwen (DashScope)                       |
| `QWEN_MODEL`         | Нет          | Модель по умолчанию (`qwen-plus` если не задана) |

## Доступные модели

- `qwen-turbo` — быстрая, экономичная
- `qwen-plus` — баланс скорости и качества (по умолчанию)
- `qwen-max` — максимальное качество

## Команды бота

| Команда             | Описание                        |
|---------------------|---------------------------------|
| `/start`            | Приветствие и инструкция        |
| `/new`              | Сброс истории диалога           |
| `/model <название>` | Смена модели Qwen               |
| Любой текст         | Отправка сообщения в Qwen       |
